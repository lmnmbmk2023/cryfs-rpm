CryFS 1.0.3 签名 RPM 仓库

本仓库通过 GitHub Pages 分发 CryFS 1.0.3 的 GPG 签名 RPM，面向 el8 全系（8.0–8.5 / Stream 8 / Rocky 8 / Alma 8） 与 el9 全系（Stream 9 / Rocky 9 / Alma 9 / RHEL 9），x86_64。

一键安装

sudo dnf config-manager --add-repo https://cryfs-rpm.7234.cc.cd/cryfs.repo
sudo dnf install cryfs
cryfs --version        # 期望 1.0.3；gpgcheck=1 自动验签，签名不对会拒装
# el9 若提示缺 FUSE2 运行时：sudo dnf install fuse-libs

信任与指纹核对（安全关键）

签名仅证明「持私钥者签过此包」，不证明构建可复现。请在安装前核对 GPG 指纹：

curl -sS -O https://cryfs-rpm.7234.cc.cd/centos8.5/RPM-GPG-KEY-cryfs-1.0.3.asc
gpg --with-fingerprint RPM-GPG-KEY-cryfs-1.0.3.asc
# 期望指纹：5926 7E53 EBD4 5672 122B  2CAF DA54 1775 AED8 69BF
  • 独立公示页：fingerprint.html
  • 密钥服务器（独立渠道）：keys.openpgp.org，Key ID DA541775AED869BF
  • 若本页指纹与密钥服务器不一致，以密钥服务器为准。

兼容系统版本（实测）

系统状态说明
CentOS 8.0–8.5 / Stream 8 / Rocky 8 / Alma 8✅ 原生glibc 2.28，与构建基线一致
CentOS Stream 9 / Rocky 9 / Alma 9 / RHEL 9✅ 兼容glibc 2.34 向后兼容，仅多需 fuse-libs
CentOS 7 / RHEL 7 及更早❌ 不支持glibc 2.17 < 要求的 2.28，且已 EOL
非 RPM 系 / 非 x86_64❌ 不交付仅提供 x86_64 RPM
